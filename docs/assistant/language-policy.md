# Immutable Language Policy

## Status

`FOUNDATIONAL / IMMUTABLE`

No lifecycle stage, prompt, task, ADR, implementation decision, or future convention may weaken or override this policy.

## User Interaction

All direct communication with the user MUST be in Brazilian Portuguese (`pt-BR`).

## Internal Project Artifacts

All project-authored internal artifacts MUST be written in English.

This includes:
- operating directives;
- assistant behavior files;
- lifecycle prompts;
- source code;
- tests;
- test names;
- comments when appropriate;
- documentation;
- architecture records;
- requirements;
- clarification records;
- decisions;
- plans;
- reports;
- audits;
- ADRs;
- continuity/memory artifacts;
- project-authored skills.

## Technical Tokens

Established technical tokens remain unchanged.

Examples:
- `React`
- `Fastify`
- `PostgreSQL`
- `useEffect`
- `appointmentId`
- `DATABASE_URL`
- `docs/spec.md`
- `npm test`

## Boundary

`Human I/O = pt-BR`

`Internal project artifacts = English`

Do not expose private chain-of-thought.
